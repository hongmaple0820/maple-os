# MapleOS Community Guide

Welcome to the MapleOS community! This guide helps you get involved.

## Ways to Contribute

### 🐛 Report Bugs
- [Open an issue](https://github.com/hongmaple0820/maple-os/issues/new) with reproduction steps
- Include server logs (`RUST_LOG=debug`) and execution ID
- Use `bug` label

### ✨ Request Features
- Open an issue with your use case
- Describe the user flow, not just the technical implementation
- Use `enhancement` label

### 💻 Write Code
- Browse [good first issues](https://github.com/hongmaple0820/maple-os/labels/good%20first%20issue)
- Read [CONTRIBUTING.md](CONTRIBUTING.md) for setup instructions
- Join our [community chat](#community-channels)

### 📝 Improve Docs
- Fix typos, add examples, improve clarity
- Translate docs to other languages
- Write blog posts about your MapleOS experience

## Good First Issues

These issues are suitable for new contributors:

| Area | What to do | Difficulty |
|------|-----------|------------|
| Frontend | Add loading skeletons to Chat panel | Easy |
| Frontend | Add keyboard shortcut help overlay | Easy |
| Backend | Add more Skill implementations (calculator, translator) | Medium |
| Backend | Add workflow node type: Send Email | Medium |
| CLI | Add `maple agents register` command | Easy |
| CLI | Add `maple triggers list/create` commands | Medium |
| Docs | Write API usage examples in OpenAPI spec | Easy |
| Docs | Create architecture decision records (ADRs) | Medium |
| Testing | Add Playwright tests for collaboration module | Medium |
| Testing | Add Rust integration tests for trigger manager | Medium |

## Code of Conduct

- Be respectful and inclusive
- Focus on constructive feedback
- Help others learn
- Credit contributors

## Release Schedule

- **Patch releases** (v2.1.x): Bug fixes, every 1-2 weeks
- **Minor releases** (v2.x.0): New features, monthly
- **Major releases** (v3.0.0): Breaking changes, quarterly
