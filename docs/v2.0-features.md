## 1. RAG-Retrievable Tools (工具向量检索)

### 概述

工具向量检索系统允许 Agent 在运行时通过语义搜索找到最相关的工具，而不是将所有工具都发送给 LLM。这显著减少了 token 使用量并提高了工具选择的准确性。

### 核心功能

```rust
use maple_agent::ToolRegistry;
use maple_llm::embedding::FallbackEmbedder;

// 创建注册表
let embedder = Arc::new(FallbackEmbedder::new(768));
let registry = ToolRegistry::new(embedder)
    .with_default_top_k(10);

// 注册工具（自动向量化）
registry.register(tool_definition).await?;

// 带分类注册
registry.register_with_category(tool_def, "filesystem").await?;

// 语义搜索
let tools = registry.search("read file from disk", Some(5)).await?;

// 分类内搜索
let tools = registry.search_in_category("read", "filesystem", Some(5)).await?;

// 使用频率排序
let tools = registry.search_with_usage_boost("file", Some(5)).await?;

// 关键词搜索（无需 embedding）
let tools = registry.search_by_keyword("file", Some(10)).await;

// 记录工具使用
registry.record_usage("read_file").await;

// 获取统计信息
let stats = registry.stats().await;
```

### 数据结构

```rust
struct ToolEntry {
    definition: ToolDefinition,
    embedding: Vec<f32>,      // 预计算的向量
    tags: Vec<String>,        // 自动提取的标签
    category: String,         // 分类标签
    use_count: u64,           // 使用次数
    last_used: i64,           // 最后使用时间
}

struct ToolRegistryStats {
    total_tools: usize,
    categories: usize,
    total_uses: u64,
    avg_embedding_dim: usize,
    default_top_k: usize,
}
```

### 搜索算法

1. **语义搜索**: 使用 cosine similarity 比较查询向量和工具向量
2. **标签匹配**: 如果查询包含标签关键词，增加 0.15 分
3. **使用频率**: 使用次数最多的工具获得最多 0.2 分的提升
4. **关键词匹配**: 匹配工具名、描述、标签、schema 属性

## 3. 终端后端扩展

### 支持的后端

| 后端 | 用途 | 特性 |
|------|------|------|
| **LocalBackend** | 本地 shell 执行 | 文件操作、环境变量、工作目录 |
| **DockerBackend** | Docker 容器隔离 | 资源限制、卷挂载、环境变量 |
| **SshBackend** | SSH 远程执行 | 密钥认证、端口配置、持久状态 |
| **BackendRegistry** | 后端注册管理 | 能力查询、可用性检测 |

### 使用方式

```rust
use maple_agent::terminal_backend::*;

// 本地执行
let backend = LocalBackend::new();
let result = backend.execute("ls -la", None).await?;
println!("Exit code: {}", result.exit_code);
println!("Stdout: {}", result.stdout);

// Docker 容器执行
let backend = DockerBackend::new("ubuntu:latest")
    .with_container_name("my-container")
    .with_volume("/host/path", "/container/path")
    .with_env("MY_VAR", "value");

let limits = ResourceLimits {
    timeout: Duration::from_secs(60),
    max_memory: 1024 * 1024 * 1024, // 1GB
    max_cpu: 50, // 50%
    max_disk: 10 * 1024 * 1024 * 1024, // 10GB
};
let result = backend.execute("apt update", Some(limits)).await?;

// SSH 远程执行
let backend = SshBackend::new("server.com", "user")
    .with_port(2222)
    .with_key("/path/to/private/key");

let result = backend.execute("uname -a", None).await?;

// 文件系统操作
backend.write_file("/tmp/test.txt", "Hello, World!").await?;
let content = backend.read_file("/tmp/test.txt").await?;
let entries = backend.list_dir("/tmp").await?;
backend.create_dir("/tmp/new_dir").await?;
backend.remove("/tmp/test.txt").await?;

// 后端注册表
let mut registry = BackendRegistry::new();
registry.register(Box::new(LocalBackend::new()));
registry.register(Box::new(DockerBackend::new("ubuntu")));

let available = registry.available_backends().await;
let gpu_backends = registry.find_with_capabilities(true, false);
```

### 资源限制

```rust
struct ResourceLimits {
    timeout: Duration,      // 最大执行时间
    max_memory: u64,        // 最大内存 (字节, 0=无限)
    max_cpu: u32,           // 最大 CPU 百分比 (0=无限)
    max_disk: u64,          // 最大磁盘空间 (字节, 0=无限)
}
```

## 4. Cron 调度器 + 自然语言任务

### 自然语言解析

```rust
use maple_agent::cron::CronExpression;

// 分钟级
let expr = CronExpression::parse_natural_language("every 5 minutes")?;
// → */5 * * * *

// 小时级
let expr = CronExpression::parse_natural_language("every 2 hours")?;
// → 0 */2 * * *

// 每天
let expr = CronExpression::parse_natural_language("daily at 9:00")?;
// → 0 9 * * *

// 每周
let expr = CronExpression::parse_natural_language("weekly on Monday at 14:00")?;
// → 0 14 * * 1

// 每月
let expr = CronExpression::parse_natural_language("monthly on day 15 at 10:00")?;
// → 0 10 15 * * *

// 快捷方式

let expr = CronExpression::parse_natural_language("daily")?;
let expr = CronExpression::parse_natural_language("weekly")?;
let expr = CronExpression::parse_natural_language("monthly")?;
```

## 5. Mock Parity Harness (确定性 Mock LLM)

### MockLlmAdapter

```rust
use maple_llm::mock_llm::*;

// 创建 mock adapter
let mut adapter = MockLlmAdapter::new("test-model");

// 添加规则
adapter.when(
    RequestMatcher::ContentContains("hello"),
    MockResponses::text("Hi there!"),
);

adapter.when(
    RequestMatcher::HasTool("read_file"),
    MockResponses::tool_call("read_file", json!({"path": "test.rs"})),
);

adapter.when(
    RequestMatcher::Always,
    MockResponses::error("Rate limited"),
);

// 设置默认响应
let adapter = MockLlmAdapter::new("test")
    .with_default_response(MockResponses::text("default"));
```

### RequestMatcher

```rust
enum RequestMatcher {
    ContentContains(String),  // 匹配消息内容
    HasTool(String),          // 匹配工具名
    MessageCount(usize),      // 匹配消息数量
    Always,                   // 总是匹配
}
```

### MockResponses

```rust
// 文本响应
MockResponses::text("Hello!")

// 工具调用响应
MockResponses::tool_call("tool_name", json!({"key": "value"}))

// 错误响应
MockResponses::error("Something went wrong")

// 带延迟的响应
MockResponses::with_latency(MockResponses::text("slow"), 1000)
```

### 请求录制

## 6. ToolSearch 运行时发现

### 关键词搜索

```rust
// 基本搜索
let tools = registry.search_by_keyword("file", Some(10)).await;

// 搜索 "file" 会匹配:
// - 工具名包含 "file" (如 read_file, write_file)
// - 描述包含 "file" (如 "Read a file from disk")
// - 标签包含 "file" (自动提取)
// - Schema 属性包含 "file" (如 "file_path")
```

### 搜索算法

1. **名称匹配** (2.0 分): 工具名完全包含查询
2. **描述匹配** (1.0 分): 描述包含查询
3. **标签匹配** (0.4 分): 标签包含查询关键词
4. **Schema 匹配** (0.2 分): Schema 属性名或描述包含查询

### 与语义搜索的区别

| 特性 | 语义搜索 | 关键词搜索 |
|------|----------|-----------|
| 需要 embedding | ✓ | ✗ |
| 搜索速度 | 较慢 | 快 |
| 语义理解 | ✓ | ✗ |
| 精确匹配 | ✗ | ✓ |
| 适用场景 | 自然语言查询 | 精确关键词查询 |

## 7. Config 层级合并 (user/project/local)

### 概述

配置层级系统允许用户在三个级别管理配置，高优先级覆盖低优先级：

1. **User** (~/.mapleos/config.yaml) — 全局默认
2. **Project** (.mapleos/config.yaml) — 项目特定
3. **Local** (.mapleos/local.yaml) — 本地覆盖 (gitignored)

### 使用方式

```rust
use maple_agent::ConfigHierarchy;

// 创建配置层级
let mut hierarchy = ConfigHierarchy::new(Path::new("/workspace"));

// 加载并合并所有级别
let config = hierarchy.load()?;

// 访问配置
println!("Provider: {}", config.llm.default_provider);
println!("Model: {}", config.llm.default_model);
println!("Temperature: {}", config.llm.temperature);

// 路径访问
if let Some(model) = hierarchy.get("llm.default_model") {
    println!("Model: {}", model);
}

// 检查来源
for source in hierarchy.sources() {
    println!("{}: {:?} (exists: {})", source.level.name(), source.path, source.exists);
}

// 保存到特定级别
hierarchy.save(ConfigLevel::Project)?;
```

### 配置结构

```rust
struct MapleConfig {
    llm: LlmConfig,        // default_provider, default_model, temperature, max_tokens, api_keys, providers
    agent: AgentConfig,     // name, system_prompt, max_iterations, enable_memory, enable_tools, settings
    tools: ToolConfig,      // enabled, disabled, settings, timeout_secs
    workflow: WorkflowConfig, // max_concurrent, retry_count, settings
    security: SecurityConfig, // audit_logging, allowed_tools, blocked_tools, max_file_size, settings
    custom: HashMap<String, Value>, // 自定义键值对
}
```

### 合并规则

- YAML 深度合并: 映射递归合并，标量值高优先级覆盖
- HashMap 字段: 合并键，高优先级覆盖同名键
- 数组字段: 高优先级替换低优先级
