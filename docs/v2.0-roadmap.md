> 目标：对标 hermes-agent/rig/claw-code 竞品优势，实现生产级 Agent OS

## 功能列表

### P0 — 核心竞争力

| # | 功能 | 描述 | 对标 |
|---|------|------|------|
| 1 | **RAG-Retrievable Tools** | 工具向量化 + 语义搜索，1000+ 工具只发送相关子集给 LLM | rig ToolEmbedding |
| 2 | **LLM Provider 生态扩展** | 支持 15+ LLM 提供商（OpenAI/Anthropic/Gemini/Claude/Ollama/DeepSeek/通义/文心等） | rig 25+ providers |

| # | 功能 | 描述 | 对标 |
